# Frontend Fornecedores

Interface do Portal de Fornecedores em Next.js, React e JavaScript com JSX.

## Preparação

```bash
npm install
```

Para apontar o frontend para a API, crie um arquivo `.env` com base em
`.env.example`.

## Desenvolvimento

```bash
npm run dev
```

A aplicação estará disponível em [http://localhost:3000](http://localhost:3000).
O código está em `src` e usa arquivos `.js` e `.jsx`. O alias `@/*` está
configurado em `jsconfig.json`.

## Validação e produção

```bash
npm run lint
npm run build
npm start
```

O lint aplica as regras recomendadas do JavaScript, React, React Hooks e Next.js.
